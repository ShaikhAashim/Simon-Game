# Simon-Game

A modern, responsive implementation of the classic Simon Says memory game built with HTML5, CSS3, JavaScript ES6+, and Bootstrap 5.

## 🎯 Features

- **Classic Gameplay**: Watch the sequence, repeat the pattern
- **Progressive Difficulty**: Each level adds one more color to remember  
- **Score Tracking**: Current score and persistent high score
- **Responsive Design**: Optimized for mobile, tablet, and desktop
- **Audio Feedback**: Unique sound for each color button
- **Visual Effects**: Smooth animations and color feedback

- ## 🎮 How to Play

1. Click **Start Game** or press **Enter** (PC/Laptop)
2. Watch the sequence of colored buttons light up
3. Click the buttons in the same order
4. Each level adds one more color to the sequence
5. Beat your high score!

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/your-username/simon-game.git
```

2. Open `index.html` in your browser

3. Start playing!
